# Cannizzo ModPatcher

Temporary local installer while the Workshop releases await moderation.

The patcher installs:

- Hot Pot House Enhanced 2.4.6
- Hot Pot House Colorblind+ Compatibility 1.0.2

It finds Steam libraries through the Windows registry and `libraryfolders.vdf`, then installs both embedded DLLs into PlateUp's local `Mods` directory. It can also remove only the copies it installed.

Required mods still need to be installed through Steam Workshop: HarmonyX, KitchenLib, Hot Pot House, Colorblind+, and Soups Plus.

Close PlateUp before installing or removing the local mods.
