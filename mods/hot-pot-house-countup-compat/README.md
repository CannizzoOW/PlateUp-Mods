# Hot Pot House - CountUp! Compatibility

Version 1.0.0.

Lets CountUp! show the remaining number of Hot Pot House side dishes. It removes the redundant floating `Dish` label and, when Hot Pot House Enhanced is present, hides its fallback counter so only CountUp!'s counter is displayed.

Required Workshop mods: HarmonyX, KitchenLib, Hot Pot House, and CountUp!.
