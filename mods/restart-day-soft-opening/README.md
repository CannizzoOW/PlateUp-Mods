# Restart Day - Soft Opening

A current PlateUp! replacement for the deprecated Workshop mod **Restart Day
(Soft Opening)** (`2927047484`).

The host receives a **Restart Day** entry in the pause menu during an active
day. A confirmation screen explains that current-day progress will be lost.
Confirming restores the run's lives and asks PlateUp to return the restaurant
to preparation for the same day.

The button is not shown during preparation or to multiplayer clients.

## Required Workshop items

- HarmonyX (`2898033283`)
- KitchenLib (`2898069883`)

Do not install this alongside another Restart Day mod.
